# 🦷 ระบบจัดการการนัดหมายคลินิกทันตกรรม (Dental Appointment System)

## 📌 เกี่ยวกับโปรเจค (About The Project)

โปรเจคนี้เป็นการพัฒนาระบบจัดการการนัดหมายสำหรับคลินิกทันตกรรมในรูปแบบ **Web Application**
มีวัตถุประสงค์เพื่อแก้ไขปัญหาการจัดการข้อมูลแบบเดิม เช่น การจดบันทึกด้วยมือ การนัดหมายผ่านโทรศัพท์หรือแชท ซึ่งอาจทำให้เกิดความผิดพลาด ข้อมูลสูญหาย หรือการนัดหมายซ้ำซ้อน 

ระบบนี้จะช่วยให้:

* การนัดหมายสะดวกและรวดเร็วขึ้น
* ลดความผิดพลาดของข้อมูล
* เพิ่มประสิทธิภาพในการให้บริการ
* มีระบบแจ้งเตือนการนัดหมาย
* สามารถออกใบเสร็จได้อย่างถูกต้อง



## 🎯 วัตถุประสงค์ของโปรเจค (Objectives)

* ศึกษาทฤษฎีและงานวิจัยที่เกี่ยวข้องกับระบบนัดหมาย
* วิเคราะห์และออกแบบระบบให้เหมาะสมกับการใช้งานจริง
* พัฒนาระบบเพื่อเพิ่มประสิทธิภาพการทำงานของคลินิก
* ประเมินความพึงพอใจของผู้ใช้งาน 



## 🚀 ฟีเจอร์หลัก (Features)

### 👨‍💼 เจ้าหน้าที่ (Admin)

* จัดการข้อมูลผู้ใช้
* จัดการข้อมูลการนัดหมาย
* อนุมัติ / ยกเลิกการนัดหมาย
* จัดการวันหยุด
* ดูตารางนัดหมาย
* บันทึกข้อมูลการรักษา
* ออกใบเสร็จรับเงิน

### 👤 ผู้ใช้บริการ (User)

* สมัครสมาชิก / เข้าสู่ระบบ
* จองคิวล่วงหน้า
* แก้ไข / ยกเลิกการนัดหมาย
* ดูตารางเวลาว่าง
* ตรวจสอบรายละเอียดการนัดหมาย
* ตรวจสอบการชำระเงิน
* ประเมินความพึงพอใจ

### 🦷 ทันตแพทย์ (Dentist)

* ดูตารางนัดหมายของตนเอง
* ยกเลิกการนัดหมาย
* บันทึกรายละเอียดการรักษา 



## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* 🌐 Web Application (Frontend + Backend)
* 🗄️ Database System
* 🔗 Internet / Web Browser
* 💻 ระบบฐานข้อมูลสำหรับจัดเก็บข้อมูลผู้ป่วยและการนัดหมาย 

*(สามารถเพิ่มเติมภาษา/เฟรมเวิร์คจริงที่คุณใช้ได้ เช่น React, Node.js, PHP, MySQL ฯลฯ)*



## 📊 โครงสร้างระบบ (System Scope)

ระบบแบ่งออกเป็น 3 ส่วนหลัก:

1. ระบบจัดการสำหรับเจ้าหน้าที่
2. ระบบสำหรับผู้ใช้บริการ
3. ระบบสำหรับทันตแพทย์

รองรับ:

* การจัดการคิว
* การจัดเก็บข้อมูลเวชระเบียน
* การจัดการค่าบริการและใบเสร็จ
* การแจ้งเตือนการนัดหมาย
